# Emoji de Noto

Los ficheros de esta carpeta salen de [Noto Color Emoji](https://github.com/googlefonts/noto-emoji),
commit `e20cbc2bbec1926686be9f9bee7d1d2cfa1fea0e` (ver `fuentes.json`, con la ruta
y el SHA-256 de cada uno). Los copia `scripts/emoji-noto.mjs`.

- **Banderas** (`third_party/region-flags/waved-svg/`): dominio público. La de
  España se guarda en PNG de 128 px (su SVG pesa 415 KB).
- **El resto de emoji** (`2D/svg/`): Apache License 2.0.
